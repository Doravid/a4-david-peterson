# Summary
I rewrote my A4 assignment to Svelte. I replaced the previous vanilla HTML and JavaScript UI. 
The Express backend needed to be updated to serve the Svelte application, it accesses the same MongoDB database and GitHub OAuth application.

# Svelte Development Experience 
It is difficult to tell if Svelte helped or hindered me. This project took less time than a3, but part of that is because I already knew exactly what I wanted, the pitfalls I might encounter, and how to handle them. Overall, Svelte did not get in the way of me recreating the app, which is impressive since I have never used it before. I found it intuitive (more so than React).
